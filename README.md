** Stock Market Simulation Application **

** This application helps users trade stock via buy, sell, and viewing components **

**This application contains the following functions**

* User Registration and Login
* Portfolio Management (Virtual Money and Stock)
* Stock List & Price Feed
* Live Updates
* Order Placement
* Order Validation
* Order Execution
* Order State Tracking
* Transaction History
* Administrative Control
* Session Control

** public URL : http://54.252.244.154 **
** please note public URL will not work as EC2 instance isn't currently running - to run locally change baseURL from live to local in axiosConfig.jsx **

** Instructions **

* npm install (Install all dependencies)
* npm start (Start Application Session)
* View through public URL or localhost://3000
* ctrl + c (Terminate Application Session)
